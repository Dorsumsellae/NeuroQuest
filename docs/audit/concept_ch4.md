# Audit « concept vs exemple » — chapitre 4 (notions ano.*)

Demande : des questions qui testent la compréhension des concepts, pas la mémoire du cas d'étude (Backblaze, colonnes du dataset, valeurs du lab, numéros de slide, noms de fonctions du notebook).
Règle appliquée : EXEMPLE = la réponse exige un détail du cas d'étude ou du lab ; MIXTE = concept, mais l'énoncé ou la bonne réponse s'appuie sur un détail mémorisé ; CONCEPT = répondable par quelqu'un qui a compris, toutes les données utiles étant dans q / ctx / code (un calcul de shape avec toutes les valeurs données est CONCEPT).
Source de vérité : `Cours/IA-Hexagone-4.Pratique-Autoencodeurs.pdf` et `content/lessons_ch34.js`. Le `why` peut toujours citer un slide.
